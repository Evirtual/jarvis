# Supporting the console

The console is free, open source (AGPL-3.0) and runs on your own keys, so
it costs nothing to run for anyone else. One way to say thanks, entirely
optional:

- **Ko-fi**: <https://ko-fi.com/edgarasneverdauskas> — a €3 coffee, one-off
  or monthly, paid by card or PayPal. Ko-fi takes nothing from donations.

Nothing is locked behind a donation, and nothing is promised for one.

## Where the link lives

- The repository's **Sponsor** button (`.github/FUNDING.yml`).
- The README's *Support* section.
- The app: one line at the bottom of Configuration → Quick.

## Why Ko-fi, and not GitHub Sponsors

GitHub Sponsors pays out only through Stripe, which needs a tax residence in
a country Stripe supports, or through a fiscal host (Open Source Collective,
about 10% of what comes in). Ko-fi pays straight into a PayPal account. If
the project grows, the fiscal-host route is still open: join at
<https://github.com/sponsors/accounts>, choose **Fiscal Host**, register the
project at opencollective.com under Open Source Collective first, and add
`github: Evirtual` to `.github/FUNDING.yml`.
